# Taste-Match 🎬🎵
### Music & Movie Taste Grouper | 

 The project explores music and movie preferences using machine learning to help users discover entertainment based on similarities in taste.

## 🚀 Live Demo

Try the application here: [Taste-Match on Streamlit](https://taste-match-g18.streamlit.app/)

## ✨ Project Overview

Taste-Match brings music and movie data together in an interactive web application. It uses data preprocessing and machine learning techniques to explore patterns in entertainment preferences and support taste-based grouping and discovery.
